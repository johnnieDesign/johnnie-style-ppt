시작할 때 한 번 훑고, 그 단계에 오면 해당 표를 다시 본다. 이 기기에 쌓인 교훈(`~/.johnnie-style-ppt/lessons.md`)이 있으면 그것도 같이 읽는다.
발표가 끝나면 새로 겪은 실패를 같은 형식(무엇이 일어났나 → 다음엔)으로 `~/.johnnie-style-ppt/lessons.md` 에 남긴다(SKILL.md 7단계).
출처: 실제 발표 한 번(2026-10, 대본 v1 · v2, HTML 장표 8파트 · 42문단 · 누름 151번, 두 맥을 오가며 준비, 발표 뒤 한 파일로 공유).

## 장면 만들기

| 실패 | 무엇이 일어났나 | 다음엔 |
| --- | --- | --- |
| 누름이 너무 촘촘 | 음성에 맞춘 167번 전환은 사람이 말하며 맞추기엔 촘촘했다. 문단 시작 + 반전만 누르고(64번) 사이를 저절로 흘리니 그 잔동작이 말 속도와 안 맞았다 | 모든 전환을 직접 누르고(151번, 약 2.9초에 한 번) 시계를 멈춘다. 1초 안에 연달아 누르는 곳은 구절을 떨어뜨리거나 합친다 |
| 헛누름 | 문단 시작에 화면이 안 바뀌는 곳은 눌러도 아무 일이 없었다 | 누를 때마다 무언가 바뀌게. 엔진은 바뀌는 게 없는 문단 시작을 첫 전환과 합친다 |
| 문단 끝 ▶ | 말을 다 마친 뒤 누르고 싶은 자리에 붙일 구절이 없었다 | `@$`(문단 끝) |
| 가운데 맞춤이 깨짐 | 마커 달린 요소를 `translateX(-50%)` 로 가운데 맞추니 엔진의 등장 transform 과 겹쳐 깨졌다 | 고정 폭 상자 + `text-align:center` |
| 흰 글자가 샘 | 글자 클래스 `.body` 와 서비스 창 본문 `.app>.body` 가 겹쳐 밝은 창 안 글자가 흰색이 됐다 | 장면 클래스 이름은 파트 접두로 가두고, 엔진 부품 이름과 겹치지 않게 |
| absolute 가 풀림 | `.abs` 뒤에 `position:relative` 를 주는 클래스가 오니 요소가 화면 폭으로 늘었다 | 위치 클래스 순서를 본다 |
| 직접 열면 도움말이 덮음 | 파일로 열면 Artifact 가 넣어 주는 `[hidden]` 규칙이 없어 시작 화면을 덮었다 | 엔진 CSS 에 `[hidden]{display:none!important}` (템플릿에 있음) |
| 로컬과 Artifact 가 다르게 보임 | doctype 없는 로컬 파일은 호환 모드, Artifact 는 표준 모드라 표 글자색 · 줄 간격이 달랐다 | 템플릿은 doctype 을 넣었다. 예전 장표를 옮길 땐 다시 찍어 비교 |
| 지어낸 값 | 메신저 채널명 · 시각, 줄여 쓴 문구, CSS 로 그린 화면 비교, 뭉뚱그린 표 칸이 사실처럼 들어갔다 | 지어낸 값은 목록으로 발표자에게 보여 주고 확인받는다 |
| 헤드리스 찌꺼기 | 남은 Chrome 이 다음 촬영을 오염시켰다 | 병렬이면 포트를 나누고, 끝나면 Chrome 이 닫혔는지 본다 |

잘 된 것

- **공통 기반 + 견본 3장면 → 파트 2개씩 병렬 4갈래 → 통합 점검.** 파트가 파일로 갈라져 있어서 병렬이 됐다
- **실제 서비스처럼 다시 그린 창**(티켓 · 시트 · 메신저 · 문서)과 서비스 로고가 추상 도형보다 잘 읽혔다
- 누를 때마다 찍어 9장씩 모아 본 것이 겹침 · 잘림 · 헛누름을 가장 빨리 잡았다

## 공유

| 실패 | 무엇이 일어났나 | 다음엔 |
| --- | --- | --- |
| 공유 서비스 용량 제한 | 안내에 없던 10MB 제한에 등록이 막혔다 | 이미지 WebP(10.5 → 1.9MB), 음성 64kbps(6.5 → 3.3MB)로 8.6MB. `build_single.py --kbps 64` |
| 샌드박스 iframe | HTML 을 샌드박스 iframe 에 띄우는 서비스에서 localStorage 는 읽기만 해도 예외, `type="module"` 막힘, 옆 파일 못 읽음 | 한 파일 + 저장은 모두 try/catch(템플릿에 있음). `check_single.mjs` 로 미리 본다 |
| 받은 사람이 못 엶 | 클라우드 드라이브에 올린 파일은 그 드라이브의 공유 권한을 그대로 따랐고, 조직 설정으로 "링크가 있는 모든 사용자" 공유가 막혀 있었다 | 공유 대상을 직접 넣는다(그룹이나 받을 사람 메일, 뷰어 · 댓글 작성자, 이메일 알림 끔) |
| Artifact 가 음성을 안 받음 | `.m4a` 를 서빙하지 않았다(contentType `audio/mp4` 도 거절) | 한 파일(data URI)로 올린다(`build_single.py`). 음성 재생은 첫 게시 때 확인 |
| Artifact 에서 서체 | CSP 가 Google Fonts 말고는 서체 파일을 막았다 | 서체는 data URI 로(`build_single.py`) |
| 공유본에 서체가 빠질 수 있었음 | 서체 도구가 없는 기기에선 서체 없이 공유본이 만들어질 수 있었다 | 서체 포함을 공유본 스펙으로: 도구는 캐시에 자동 준비, 서체를 못 찾으면 만들지 않음, `check_single.mjs` 서체 내장 검사 통과 뒤 공유 |
| 보는 사람에게 리허설 문구 | 공유본 시작 화면에 "클릭할 곳마다 ▶" 리허설 안내가 남았다 | 공유본은 `--mode rehearse`, 안내는 "자동으로 넘어갑니다"(템플릿에 있음) |
