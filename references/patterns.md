# 장면 패턴

장면을 만들 때 문단마다 아래에서 패턴을 하나 고른다. 견본은 일반 예로 다시 만든 것이고, 짜임 · 시간차 · 밀도는 실제 발표에서 잰 손맛 그대로다.

- 코드: `gallery/scenes/NN.js`(파트 하나 = 패턴 하나). 짜임과 수치를 가져오고, 일반 예는 이 발표의 대본 · 실제 화면으로 바꾼다
- 움직임 보기: `python3 scripts/new_deck.py <임시 폴더> --gallery` → `<임시 폴더>/deck/index.html` 을 열고 → · Space 로 넘긴다
- 캡처: `gallery/shots/`. 견본은 20문단에 누름 66번(문단당 2~5번)이다
- 손맛 수치(시간차 · 밀도 · 이어 가기 · 선 · 강조 상자 · 상태 모션)와 걸리기 쉬운 것은 발표 폴더의 `deck/scenes/STYLE.md`

## 고르는 법

| 대본이 하는 말 | 패턴 |
| --- | --- |
| 가져갈 한 문장 · 바뀐 것 · 숫자로 궁금하게 | 01 선언 · 교체 · 숫자 |
| 모두가 아는 답을 뒤집는다 | 02 통념 뒤집기 |
| 실제 화면의 어디인지 짚는다 | 03 화면에서 짚기 |
| 같은 것을 두고 한 곳의 차이 · 셋의 판단이 갈린다 | 04 같은 것 세 장 |
| 거의 같아 보이는 두 버전의 차이 | 05 겹쳐 비교 |
| 일이 흘러가는 순서 | 06 일의 흐름 |
| 누가 무엇을 어디로 보내는지 | 07 흐름도 |
| 사람이나 에이전트가 하는 일을 시간 순서로 | 08 하루 따라가기 |
| 끝맺음 | 09 마무리 |

이야기 장치(`references/script.md`)와 함께 고르면 빠르다. 박자의 `구절` 은 마커를 건 대본 구절이다.

## 01 선언 · 교체 · 숫자 (가운데)

![01 선언 · 교체 · 숫자](../gallery/shots/01.png)

- **이야기 장치**: 아는 사건으로 시작 · 성공 뒤 반전 · 숫자 하나로 미스터리
- **01-01 한 문장 선언** (누름 2): 제목 → `가져갈 말 하나를` 에서 문장이 타자로 찍히고 끝 단어만 강조색(`fx-pop`)
- **01-02 같은 자리 교체** (누름 3): 제목 → 화면 조각과 칩 '전' → `후로 바꿉니다` 에서 같은 자리가 `data-state` 로 후 모습, 칩 '후'(강조색). 전이 빠진 뒤 후가 0.15초 늦게 들어와 글자가 겹치지 않는다
- **01-03 숫자와 격자** (누름 4): 제목 → 큰 숫자 세기(`data-seq`) → 격자 300칸(`.cells`)이 들어오며 숫자는 옆으로 비켜선다(`data-state`) → 42칸과 숫자가 함께 강조색
- **가져갈 때**: 숫자는 사라지지 않고 비켜서야 다음 화면과 이어진다

## 02 통념 뒤집기 (가운데 → 왼쪽 · 오른쪽)

![02 통념 뒤집기](../gallery/shots/02.png)

- **이야기 장치**: 통념을 대신 말하고 뒤집기
- **02-01** (누름 2): 제목과 대상(버튼) → `버튼 하나 바꾸면` 에서 말풍선(`.bubble` + `.who`)과 대상의 강조 상자
- **02-02** (누름 4): 왼쪽 문서 창에 목록 다섯 줄(0.12초 간격) → `이게 전부일까요` 오른쪽 큰 물음표 → `목록에 없던 곳이` 강조색 세 줄이 더해짐(0.15초 간격) → `세 곳 더` 물음표 자리가 +3 으로
- **가져갈 때**: 나중에 붙을 줄의 자리를 미리 비워 두면 창 크기가 변하지 않는다

## 03 화면에서 짚기 (왼쪽)

![03 화면에서 짚기](../gallery/shots/03.png)

- **이야기 장치**: 자료(실제 화면)를 보여 줄 때
- **03-01** (누름 2): 휴대폰 화면(`.phone` 안 HTML) → `잘라서 크게` 에서 그 자리 점선 → 연결선(`fx-draw`) → 같은 화면을 크게 키운 확대 상자(`overflow:hidden`, `fx-pop`)
- **03-02** (누름 4): `위쪽 배너` · `가운데 카드` · `맨 아래 버튼` 마다 강조 상자(`.hlbox`)와 이름이 하나씩 쌓인다
- **가져갈 때**: 실제 발표에서는 `refs/` 의 실제 캡처를 잘라 같은 짜임으로 쓴다. 확대 상자는 같은 이미지를 크게 하고 `object-position` 으로 그 자리를 맞춘다

## 04 같은 것 세 장 (왼쪽)

![04 같은 것 세 장](../gallery/shots/04.png)

- **이야기 장치**: 3단 + 마지막 반전
- **04-01** (누름 3): 제목 → 카드 세 장(0 · 0.2 · 0.4초) → `가격 표시 하나만` 에서 가격 줄만 셋이 다르게 바뀌고 그 줄에 빨강 테두리
- **04-02** (누름 3): 카드는 그대로 두고 상태만 되돌린 뒤 칩 팀원 1 · 2 · 3 → `셋 다 달랐습니다` 카드마다 다른 자리에 강조 상자(0 · 0.25 · 0.5초) → `빨간 상자가` 상자 자리만 남기고 흐리게
- **가져갈 때**: 카드 묶음 하나의 `data-state`(같음 → 가격 → 같음 → 강조)로 움직인다. 강조 상자를 대상 요소 안에 넣으면 위치를 재지 않아도 맞는다

## 05 겹쳐 비교 (왼쪽)

![05 겹쳐 비교](../gallery/shots/05.png)

- **이야기 장치**: 성공 뒤 반전(같아 보였는데 어긋났다)
- **05-01** (누름 3): 전 · 후를 나란히 → `반투명하게 포개면` 후가 전 위로 미끄러져 반투명하게(0.6초) → `어긋난 곳이` 두 번 보이는 곳에 점선 셋(0 · 0.15 · 0.3초)
- **05-02** (누름 3): `빨갛게 칠하면` 어긋난 것만 빨강(점선은 사라진다) → `눈이 그곳으로` 나머지를 흐리게
- **가져갈 때**: 판 하나의 `data-state`(나란히 → 포개기 → 빨강 → 흐리게). 같은 것과 어긋난 것을 클래스로 나눠 두면 상태마다 한 줄로 바뀐다

## 06 일의 흐름 (왼쪽)

![06 일의 흐름](../gallery/shots/06.png)

- **이야기 장치**: 라벨 구조(단계 이름이 귀에 남는다)
- **06-01** (누름 3): 제목 → 단계 네 칸과 화살표가 왼쪽부터(0~0.45초) → `완료에서 끝납니다` 끝 칸 강조
- **06-02** (누름 5): 줄이 위로 올라가며 흐려지고 지금 단계만 켜진다. `메신저의 요청이` 메신저 창 → `시트의 한 줄이` 시트 창(새 줄이 늦게) → `그 줄이 티켓이` 지라 창, 시트의 티켓 칸이 채워짐 → `완료로 바뀝니다` 시트 상태 칩이 완료로
- **가져갈 때**: 같은 요청 문구가 메시지 → 시트 줄 → 티켓 설명으로 이어지게 쓴다. 단계 줄은 `data-state`(s0~s4) 하나로

## 07 흐름도 (가운데)

![07 흐름도](../gallery/shots/07.png)

- **이야기 장치**: 구조 설명(누가 무엇을 어디로)
- **07-01** (누름 4): 제목 → 출발점 넷(0.12초 간격) → `선을 그려` 잉크색 선(`fx-draw`, 0.1초 간격) → `가운데로` 가운데 상자(`fx-pop`)
- **07-02** (누름 3): 그림은 그대로 두고 제목만 바꾼다 → `다시 사람에게` 강조색 선과 사람 칩(선 뒤 0.4~0.6초) → `순서대로` 출발 → 도착 한 줄
- **가져갈 때**: 선 끝이 상자 · 칩 가장자리에 정확히 닿게 좌표를 맞춘다. 모이는 선은 잉크색, 나눠 주는 선은 강조색

## 08 하루 따라가기 (왼쪽)

![08 하루 따라가기](../gallery/shots/08.png)

- **이야기 장치**: 의인화 · 하루 따라가기
- 시간 막대 하나를 파트 끝까지 두고 `data-state` 로 채움 · 지금 점 · 시각 글자만 옮긴다
- **08-01 오전** (누름 5): 제목 → 막대 → 첫 시각 점 → 밤사이 메신저 → 하루 리포트 창
- **08-02 오후** (누름 3): 시각 이동 → 터미널 창 → 경고 줄과 바뀐 규칙(지운 줄 · 새 줄)
- **08-03 저녁** (누름 4): 시각 이동과 버그 한 줄, 세 창(바뀌기 전) → 세 창이 차례로 바뀜(강조 상자) → 30 세기와 리포트 목록
- **가져갈 때**: 시각이 바뀌는 누름에서는 앞 장면만 퇴장하고 점이 미끄러진다. 바뀌는 것이 보이게 바뀌기 전 상태를 먼저 띄운다

## 09 마무리 (왼쪽 → 가운데)

![09 마무리](../gallery/shots/09.png)

- **이야기 장치**: 복선과 콜백 · 청중 호출로 끝내기
- **09-01** (누름 4): 제목 → 가져갈 것 세 줄이 구절마다 한 줄씩. 진짜 순서라 번호를 쓰고, 번호는 흐린 색
- **09-02** (누름 2): 시작에 세 줄을 흐리게(헛누름 없이) → `감사합니다` 에서 세 줄이 빠지고 가운데 인사만
